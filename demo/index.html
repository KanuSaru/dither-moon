dither-moon

The Moon at its real phase, right now, drawn as 1-bit dithered pixel art. A tag for any web page, a React component, and the phase math on its own.

 

Source on GitHub

Use it

Any web page

<script src="https://cdn.jsdelivr.net/gh/KanuSaru/dither-moon@v1.0.0/dist/dither-moon.js"></script>
<dither-moon style="width: 240px"></dither-moon>

React

npm install github:KanuSaru/dither-moon#v1.0.0

import { DitherMoon } from "dither-moon/react";
<DitherMoon style={{ width: 240, color: "#e7e2d6" }} />

Just the phase

import { moonPhase, nextFullMoon } from "dither-moon";
moonPhase();      // { phaseName: "Waxing gibbous", illumination: 0.83, … }
nextFullMoon();   // Date
